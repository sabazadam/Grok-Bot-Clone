How will you use GrokBot?

You can change this anytime from the GrokBot menu → Settings.

Run on this device

Start the GrokBot server here and use it locally. Requires Docker + Node on this machine.

Connect to a server (commander)

This machine is a client. Point it at a GrokBot server running elsewhere — e.g. your Mac mini over Tailscale.

The server runs from here using your system Node (so native modules & the agent image are reused).
Use the URL your Mac mini serves — e.g. its Tailscale IP on port 8484 (or 5173 in dev).
